# Awesome Obsidian Plugin Collection

[English](README_en.md) | [中文](README.md)

A carefully crafted collection of Obsidian plugins designed to enhance your note-taking and organization efficiency.

## Plugin List

### 1. Unreferenced Attachments Scanner
Quickly identify unreferenced attachments in your vault to help clean up redundant files and keep your library organized.

**Key Features:**
- One-click scan for unreferenced local attachments (images, PDFs, archives, etc.)
- Intuitive right-sidebar view for results
- Support direct deletion to trash or copy paths
- Whitelist folders to ignore specific directories

### 2. Attachment Link Rewriter
Batch rewrite inline image links in notes with custom templates and attachment move/copy support.

**Key Features:**
- Customizable link format templates
- Three operations supported: modify links only, move attachments, copy attachments
- Scope limitation (current file/specified file/specified folder)
- Whitelist mechanism to skip specific notes

### 3. Filename to Title Sync
Automatically synchronize filenames with the `title` field in YAML front matter.

**Key Features:**
- Automatically update title field in YAML when files are renamed
- Manual sync command available
- Maintain consistency between filenames and document titles

## Installation Guide

### Method 1: Manual Installation
1. Download this project or clone the repository
2. Copy the desired plugin folders to your vault directory: `.obsidian/plugins/`
3. In Obsidian, go to Settings → Third-party Plugins
4. Enable the corresponding plugins

### Method 2: Individual Plugin Installation
Please refer to the specific installation instructions in each plugin directory's README file.
