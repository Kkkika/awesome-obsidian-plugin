 # 附件链接重写器（Attach Link Rewriter）
 
 一句话介绍：批量重写笔记中的内联图片链接，支持模板、移动/复制附件。
 
 - 作者：kika
 - 版本：0.1.0
 - 适配：Obsidian ≥ 1.4.0（桌面与移动端）
 
 ## 简介
 - 将 Markdown 文档中的内联图片链接统一重写为自定义相对路径结构（如 `./../{{docName}}/{{attName}}`），保持库内附件组织有序。
 - 支持三种操作：仅改链接、移动附件、复制附件；可限定于“当前文件 / 指定文件 / 指定文件夹”范围执行。
 - 提供白名单以跳过不希望被处理的笔记路径。
 - 零构建、纯 JavaScript，安装即用。
 
 ## 安装指南
 - 手动安装
   1. 将文件夹 `attach-link-rewriter` 放入库目录 `.obsidian/plugins/`。
   2. 设置 → 第三方插件 → 打开「允许社区插件」。
   3. 在插件列表中启用「附件链接重写器」。
 - 升级/移除
   - 升级：替换同名文件夹内容并重启 Obsidian。
   - 移除：在插件列表关闭后，删除该插件文件夹。
 
 ## 快速上手
 1. 打开 设置 → 第三方插件 → 附件链接重写器。
 2. 在“作用范围”中选择要处理的目标（当前文件 / 指定文件 / 指定文件夹）。若选择文件或文件夹，请在“目标路径”中填写或浏览库内相对路径。
 3. 保持默认“链接格式”为 `./../{{docName}}/{{attName}}`，并将“文件操作”设为“ 不移动 ”（仅修改链接）。
 4. 点击“运行一次”，或在命令面板执行「批量修改内联图片（一次）」。
 5. 示例：当笔记为“项目/周报.md”，引用图片“logo.png”，默认模板会将链接改写为 `./../周报/logo.png`。
 
 ## 功能详解
 - 作用范围
   - 当前文件：仅处理当前活动笔记。
   - 选择文件：仅处理指定 Markdown 文件。
   - 选择文件夹：处理该文件夹及其子文件夹内所有 Markdown 文件。
   - 目标路径：当范围为“选择文件/选择文件夹”时生效；路径为库内相对路径，如 `Notes/每日.md` 或 `Assets/图片/`。
 - 链接格式（模板）
   - 可用变量：
     - `{{docName}}`：当前笔记名（不含扩展名）
     - `{{attName}}`：附件完整文件名（含扩展名）
     - `{{attBase}}`：附件文件名（不含扩展名）
     - `{{ext}}`：附件扩展名（小写、无点）
   - 默认模板：`./../{{docName}}/{{attName}}`
 - 文件操作
   - 不移动：仅修改笔记中的链接文本。
   - 移动：将附件移动到新位置并更新链接。
   - 复制：复制附件到新位置并更新链接。
   - 注意：若目标位置存在同名文件，可能被覆盖，请先做好备份。
 - 处理对象
   - 仅处理 Markdown 内联图片语法：`![alt](path "title")`
   - 仅支持图片扩展名：png、jpg、jpeg、gif、webp、svg、bmp、tif、tiff
   - 跳过以 `http(s):` 与 `data:` 开头的外链；目标为 `.md` 的链接不处理
 - 白名单
   - 在设置页通过“浏览”添加要跳过处理的笔记路径（库内相对路径），支持清空。
 
 ## 配置/自定义
 - 设置项入口：设置 → 第三方插件 → 附件链接重写器
 - 推荐配置思路
   - 想统一把图片归档到“与笔记同名的文件夹”内：保留默认模板 `./../{{docName}}/{{attName}}`，选择“移动”或“复制”。
   - 想仅规范链接而不改动文件位置：选择“ 不移动 ”。
 - 二次开发
   - 可在 `main.js` 中扩展支持的资源类型、模板变量或命令。
 
 ## 常见问题（FAQ）
 - 为什么运行后没变化？
   - 确认选择的“作用范围/目标路径”包含了目标笔记；目标链接为标准内联图片语法，且指向本地图片文件；等待 Obsidian 完成索引后再试。
 - 支持 wiki 图片（如 `![[img.png]]`）吗？
   - 当前版本仅处理标准 Markdown 内联图片语法。
 - 如何仅修改链接不移动文件？
   - 在“文件操作”选择“ 不移动 ”。
 - 模板里的相对路径是相对于哪里？
   - 相对于当前笔记所在目录；插件会做基础的路径归一化与父目录创建。
 - 会覆盖同名目标吗？
   - `移动/复制` 时若目标已存在同名文件，可能覆盖。执行前请备份或调整模板避免冲突。
 
 ## 已知问题/限制
 - 仅处理图片资源；其他附件（如 PDF、音频、视频）暂未纳入。
 - 仅支持标准内联图片语法；不处理 wiki 图片或普通链接。
 - 大量文件批量处理可能耗时，建议分文件夹执行。
