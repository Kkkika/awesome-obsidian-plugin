# 文件名与标题同步插件

[English](README_en.md) | [中文](README.md)

自动同步文件名与 YAML 前置元数据中的 `title` 字段，保持文件名与文档标题的一致性。

## 概述

这款 Obsidian 插件会在重命名 Markdown 文件时自动更新文件 YAML 前置元数据中的 `title` 字段。同时还提供了手动同步命令来确保标题一致性。

## 功能特性

- **自动同步**：当 Markdown 文件重命名时自动更新 `title` 字段
- **手动同步**：通过命令面板集成实现按需同步
- **跨平台**：支持 Obsidian 的桌面版和移动版
- **智能检测**：仅处理带有 YAML 前置元数据的 `.md` 文件

## 安装方法

### 手动安装
1. 下载或克隆此仓库
2. 将 `filename-to-title-sync` 文件夹放置到您的 vault 的 `.obsidian/plugins/` 目录中
3. 在设置 → 社区插件中启用社区插件
4. 从插件列表中激活"文件名与标题同步"

### 更新与卸载
- **更新**：替换插件文件夹内容并重启 Obsidian
- **卸载**：在插件列表中禁用并删除插件文件夹

## 使用方法

### 自动同步
1. 在您的 vault 中选择任意 Markdown 文件
2. 使用 F2 或右键上下文菜单重命名文件
3. YAML 前置元数据中的 `title` 字段将自动更新以匹配新文件名

### 手动同步
1. 打开命令面板 (Ctrl/Cmd+P)
2. 执行"同步当前文件的文件名到标题"
3. 当前文件的标题将被更新并显示确认通知

## 配置选项

目前没有内置的配置选项。如需自定义字段名称，请修改 `main.js` 中的 `frontmatter['title']` 并重新加载插件。

## 故障排除

**问：为什么重命名不起作用？**
- 确保目标文件是 `.md` 文件且插件已启用
- 只有重命名事件和手动命令才会触发同步
- 需要 Obsidian 版本 ≥ 0.15.0

**问：没有 YAML 前置元数据的文件会怎样？**
- Obsidian 会自动创建 YAML 块并添加 `title` 字段

**问：手动命令在哪里？**
- 通过命令面板 (Ctrl/Cmd+P) → "同步当前文件的文件名到标题" 访问

**问：它会覆盖现有的 `title` 值吗？**
- 是的，这是设计初衷。插件维护标题-文件名一致性。如果需要自定义标题请避免使用。

**问：与其他前置元数据插件的兼容性如何？**
- 如果其他插件修改 `title` 字段可能会发生冲突。可根据需要调整加载顺序或字段名称。

## 限制条件

- 仅响应重命名事件；批量操作需要手动命令
- 仅限 Markdown 文件
- 直接覆盖 `title` 字段而不采用合并策略
