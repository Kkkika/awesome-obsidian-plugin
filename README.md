# Awesome Obsidian Plugin 集合

[English](README_en.md) | [中文](README.md)

这是一套精心制作的 Obsidian 插件集合，旨在提升您的笔记管理和组织效率。

## 插件列表

### 1. 未引用附件扫描 (Unreferenced Attachments)
快速找出库内未被任何 Markdown 文档引用的附件，帮助清理冗余文件，保持库整洁。

**主要功能：**
- 一键扫描未引用的本地附件（图片、PDF、压缩包等）
- 右侧视图直观展示结果
- 支持直接删除到回收站或复制路径
- 可设置白名单文件夹忽略特定目录

### 2. 附件链接重写器 (Attach Link Rewriter)
批量重写笔记中的内联图片链接，支持自定义模板和附件移动/复制。

**主要功能：**
- 自定义链接格式模板
- 支持仅修改链接、移动附件、复制附件三种操作
- 可限定处理范围（当前文件/指定文件/指定文件夹）
- 白名单机制跳过特定笔记

### 3. 文件名与标题同步 (Filename to Title Sync)
自动同步文件名与 YAML 前置元数据中的 `title` 字段。

**主要功能：**
- 文件重命名时自动更新 YAML 中的 title 字段
- 提供手动同步命令
- 保持文件名与文档标题一致性

## 安装指南

### 方法一：手动安装
1. 下载本项目或克隆仓库
2. 将需要的插件文件夹复制到您的 vault 目录：`.obsidian/plugins/`
3. 在 Obsidian 中打开 设置 → 第三方插件
4. 启用相应的插件

### 方法二：单个插件安装
请参考各插件目录下的具体安装说明。

## 使用说明

每个插件都有详细的使用文档，请查看对应插件文件夹中的 README 文件获取具体使用方法。

## 系统要求

- Obsidian v0.15.0 或更高版本
- 支持桌面版和移动版
