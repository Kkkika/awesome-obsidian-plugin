# 未引用附件扫描（Unreferenced Attachments）

一句话介绍：在设置页一键扫描，右侧视图列出未被 Markdown 引用的本地附件，支持直接删除与复制路径。

- 作者：kika
- 版本：0.1.0
- 最低 Obsidian 版本：1.2.0

## 简介
- 快速找出库内未被任何 Markdown 文档引用的附件（如图片、PDF、压缩包等），帮助清理冗余文件，保持库整洁。
- 零构建、纯 JavaScript，安装即用。

## 安装指南
- 将本插件文件夹复制到你的库目录：`.obsidian/plugins/unreferenced-attachments/`
- 打开 Obsidian → 设置 → 第三方插件 → 启用“未引用附件扫描”

## 快速上手
- 打开 设置 → 第三方插件 → 未引用附件扫描
- 点击“开始扫描”
- 结果在右侧侧栏视图显示：可点击打开附件、复制路径，或直接删除到回收站

## 功能详解
- 扫描范围
  - 解析库内所有 Markdown 的 links 与 embeds，解析到的目标落地为实际文件后进行统计
  - 将所有非 `md` 文件视为“附件”，与“被引用附件集合”求差得到未引用列表
- 结果视图
  - 固定在右侧侧栏展示，不遮挡正文或图片预览
  - 每一项提供“打开”“删除”“复制路径”操作
- 删除策略
  - 优先移动到系统回收站（`vault.trash(file, true)`），不可用时回退为直接删除
- 白名单文件夹
  - 在设置页通过“添加目录”浏览选择要忽略的文件夹
  - 白名单目录下的 Markdown 与附件均不参与扫描与结果

## 配置/自定义
- 白名单文件夹
  - 位置：设置 → 第三方插件 → 未引用附件扫描 → 白名单文件夹
  - 操作：点击“添加目录”选择；在下方列表可逐项移除
- 视图位置
  - 可将右侧视图页签拖动到底部或左侧，按个人习惯布局

## 常见问题（FAQ）
- 扫描后没有结果，但我确定有未使用的图片？
  - 等待 Obsidian 完成索引后再试；检查该图片是否被任意 Markdown 通过 link/embed 引用
- 删除按钮没反应或失败提示？
  - 检查系统权限或磁盘状态；如系统回收站不可用，插件会回退为直接删除
- 误删了文件怎么办？
  - 优先进入系统回收站，可自行还原；若被直接删除，请使用你的备份方案恢复
- 移动端可用吗？
  - 插件未做移动端专门适配，侧栏视图在手机/平板上的表现可能与桌面端不同

## 已知问题/限制
- 不解析 frontmatter 自定义路径字段，仅统计标准 links 与 embeds
- 不处理外链或网络资源
- 当库内文件极多时，首次扫描可能需要较长时间
